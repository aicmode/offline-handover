申し送りメーカー 使い方

初めて使う方へ — まずこれだけ

毎日の基本操作は次の7つです。

  1. 画面上部で対象日を確認
  2. 使用するUnitを選択
  3. 「申し送り入力」を開く
  4. 変更があった入居者だけ内容を確認・修正
  5. 必要に応じて予定を登録
  6. 印刷プレビューを確認
  7. 印刷
毎日ゼロから入力する必要はありません。 前日の申し送りは、今日を初めて開いたときに自動で引き継がれます。変更がある部分だけ修正してください。
前日から引き継がれた内容は必ず確認し、古い情報を残さず、現在の状態に合わせて修正してください。
過去日・未来日は「見るだけ」では何も作られません。 カレンダーで別の日を開いても、申し送りが自動で作られたり書き換わったりすることはありません。先の日付へ引き継ぎたいときだけ「前日の申し送りをこの日に引き継ぐ」を押してください。

申し送り入力

入居者ごとに、常設重要メモ、今日あったこと、本日の申し送り、前日引継ぎ、予定追加を操作します。入力はこのPCのブラウザ内へ自動保存されます。

常設重要メモ

転倒注意、左上肢BP不可、食事トロミ、移乗見守りなど、毎日引き継ぐ重要事項です。日付が変わっても保持されます。

今日あったこと

発熱や転倒など、その日に起きた事実を入力します。日付が変わっても自動コピーされません。

本日の申し送り

他スタッフへ伝える内容で、用紙へ印刷されます。自動引継ぎがONの入居者は、前日の内容が引き継がれます。引継ぎ後は「確認済み」を押す前に必ず内容を見直してください。

前日申し送りの自動引継ぎ
  • 自動で引き継ぐのは「今日」を初めて開いたときだけです。
  • 過去日・未来日を開いただけでは引継ぎされません。先の日付を続けて確認しても、申し送りが次々と作られることはありません。
  • すでにその日に入力がある入居者は上書きしません。
  • 空床・退居の入居者は対象外です。
  • 入居者ごとのON/OFFは入居者マスターの「自動引継ぎ対象」で設定します。

今日以外の日付へ引き継ぎたいときは、「前日の申し送りをこの日に引き継ぐ」を押してください。この操作でだけ、その日のデータが作られます。

簡潔化する／申し送り作成

入力した内容を短く整理する補助機能です。処理はこのHTML内のルールで行い、外部AIへ送信していません。

自動生成された内容は必ず確認し、意味や最新の状態が正しいか確かめてから使用してください。

「前日からコピー」は現在Unitの未入力者へ、「別の日からコピー」は選んだ日の内容をコピーします。既存の内容を不用意に上書きしないため、画面の確認に従ってください。

入居者追加、部屋番号、入居者名、空床、並び順、常設重要メモ、自動引継ぎ対象、記録項目設定、履歴を管理します。1 Unitは最大30名です。

  • ↑↓：印刷時の並び順を変更します。「部屋番号順に並べ替え」も使えます。
  • 自動引継ぎ対象：ONの入居者だけ前日の本日の申し送りを翌日へ自動で引き継ぎます。
  • 履歴を見る：その入居者に絞って履歴検索を開きます。
空床：「空床」にすると、実入居人数の計算と印刷対象から自動的に除外されます。
退居（通常はこちらを使います）

入居者が退居したときは、一覧右端の「退居」を押します。

  • 申し送り入力の一覧に表示されなくなります
  • 実入居人数・申し送り印刷・前日自動引継ぎの対象から外れます
  • 過去の申し送り・過去の予定・履歴はそのまま残ります（履歴検索で確認できます）
  • 退居時点で残っている今後の予定も削除しません。件数を確認のうえ保持します
  • 「退居した入居者も表示する」にチェックを入れると一覧に表示され、「復帰」で在籍へ戻せます
完全削除（管理用操作・取り消せません）

完全削除は「データ管理」の「管理用操作」の中にあります。過去の申し送り・予定・履歴まですべて消え、元に戻せません。二段階の確認が必要です。

記録を残す必要がある場合は、完全削除ではなく「退居」を使用してください。完全削除の前には必ずバックアップ保存を行ってください。
この Unit の対象日データを全消去

「データ管理」の削除ボタンは、いま表示している Unit・対象日の日次データだけを消去します。他の Unit は変更されません。全 Unit をまとめて消す操作は「管理用操作」の中にあります（二段階確認）。

記録項目設定（日勤・夜勤）

入居者ごとに、日勤と夜勤で必要な記録項目を個別にON/OFFできます。OFFの項目は印刷欄に出ません。

  • T：体温
  • P：脈拍
  • BP：血圧
  • SpO2：経皮的酸素飽和度
  • 食事：朝・昼・夕
  • Hr：指定された回数（1回目・2回目）の記録欄
  • BS：血糖測定（通常BS・ターゲスBS・翌朝BSなど）
  • BW：体重
  • メモ：自由記入
曜日指定

P・BP・BS・BWなどは必要な曜日だけ表示できます。「毎日」を外し、曜日を選択してください。

例：BPを「月・木」に設定 → 月曜日と木曜日だけ印刷欄にBPが表示されます。
BSターゲス（設定画面では「ターゲスBS」）

指定曜日の日勤欄に、1回目・2回目・3回目の3枠を表示します。

翌朝BS

測定する朝の曜日を指定します。たとえば木曜日の朝にBS測定が必要な入居者は、水曜日の夜勤欄に「翌朝BS（木）」が自動表示されます。曜日計算はアプリが行うため、スタッフが前日を計算する必要はありません。

カスタム項目

施設独自の水分量、排便、尿量、疼痛、酸素流量、睡眠時間などを追加できます。項目名・勤務帯・曜日・単位・入力欄サイズを設定できます。

予定の登録と予定一覧

予定一覧は、受診、外出、外泊、面会、行事、その他を管理する場所です。

申し送り文章へ入力しただけでは、予定一覧へ自動登録されません。入居者カードの「＋予定を追加」または「今日あったことから予定として抽出」を使って登録してください。

予定には、日付、種別、開始時間、終了時間、内容、病院名／場所、診療科、家族付き添い、補足メモを登録できます。

予定一覧の印刷（申し送り用紙とは別紙）

予定は申し送り用紙には印刷されません。「予定一覧」タブの「予定一覧を印刷」から、A4横の専用用紙として印刷します。申し送り用紙は、その分だけ記録欄・申し送り欄を広く使えます。

  • 印刷されるのは対象日（画面上部の日付）の1日分です。
  • 「全Unit」がONのときは Unit 2〜5 をまとめて印刷し、Unitごとの見出しで区別します。OFF のときは現在の Unit だけを印刷します。
  • Unit・部屋番号・入居者名・予定種別・開始時間・終了時間・予定内容・病院名／場所・診療科・家族付き添い・補足メモを一覧で印刷します（未入力の項目は「−」）。
  • 並び順は Unit → 開始時間 → 入居者の並び順です。
  • 予定が1件もない日は「この日の予定はありません」と印刷されます。
  • 編集ボタン・チェックボックスなどの操作画面は印刷されません。
過去予定

予定日を過ぎると通常一覧では非表示になりますが、データは残ります。「過去の予定も表示する」をONにすると見返せます。

過去予定が増えると整理を提案しますが、勝手に自動削除はしません。「過去予定を整理」で対象を確認してから削除してください。

退居した入居者の予定も削除されません。予定一覧・予定一覧印刷では「退居」と表示されるので、対応が必要か確認してください。

履歴検索

過去の出来事、過去の申し送り、受診、外出、外泊、面会、行事、その他予定などを検索できます。

検索例：「発熱」「転倒」「カロナール」「○○病院」「山田太郎」

フリーワード、Unit、開始日・終了日、種別で絞り込み、新しい順／古い順を選べます。検索結果を押すと、その日や入居者の内容を確認できます。

退居した入居者の履歴も検索できます。結果には「退居」と表示され、Unit・部屋番号・氏名も当時の記録から表示されます。

履歴検索は「見るだけ」の機能です。検索しても、結果を開いても、新しい申し送り・予定・入居者データは作られません。

保存・バックアップ・別PCへの移行

データはどこに保存されるか
  • データはこのPCの、いま使っているブラウザの中（localStorage）に保存されます。外部サーバーへ自動アップロードされません。
  • index.html というファイルの中に入居者データが書き込まれるわけではありません。
  • そのため、HTMLファイルだけを別のPCへコピーしてもデータは移りません。
  • 同じPCでも、別のブラウザ（Edge / Chrome など）で開くと別の保存場所になります。
  • ブラウザの「閲覧データの削除」「サイトデータの削除」や、プライベート（シークレット）ウィンドウでの使用により、保存データが失われることがあります。
定期的なバックアップ保存を強くおすすめします。バックアップがあれば、PCの入れ替えやデータ消失からも復旧できます。
バックアップ保存・復元
  • バックアップ保存：現在のアプリデータをJSONファイルとして保存します。
  • バックアップ復元：保存済みバックアップファイルからデータを戻します。現在のデータは読み込んだ内容へ完全に置き換わり、元に戻せない場合があります。
  • 復元の操作では、先に「現在のデータをバックアップ保存してから復元する」かを確認します。迷ったときは保存してから進めてください。
  • ファイルの形式が違う場合は「読み込めませんでした（形式が違います）」と表示され、現在のデータは変更されません。
バックアップには入居者情報、申し送り、過去履歴、予定、設定などが含まれます。個人情報を含む可能性があるため、保管場所・持ち出し・廃棄に注意してください。
別PCへ移すとき

index.htmlを別PCへコピーしただけでは、現在PCのブラウザ内のデータは移りません。

バックアップ保存 → バックアップファイルを別PCへ安全に移動 → 別PCでバックアップ復元

アプリHTMLを更新版へ差し替える前にも、念のためバックアップ保存を推奨します。同じPC・同じブラウザでも、ブラウザデータの消去や保存場所の違いでデータが見えなくなることがあります。

保存状態の表示
  • 保存中…：入力内容を保存しています（数百ミリ秒で終わります）。
  • ✓ 保存済み：このPCへ保存できています。
  • メモリ保存：このPCへ保存できていません。画面上部に赤い警告が出ます。
「⚠ 現在データをこのPCへ保存できていません」と表示された場合、そのページを閉じると入力内容が失われる可能性があります。すぐに「いますぐバックアップ保存」でファイルへ保存し、保存環境（プライベートモード・保存容量・ブラウザのサイト設定）を確認してください。保存できる状態に戻ると、警告は自動的に消えます。

入力は自動保存されますが、タブの切り替え・最小化・ページを閉じるときにも未保存の変更を自動で保存します。

昨日の申し送りが表示されない

前日データが存在するか、画面上部の「前日申し送り自動引継ぎ」と、入居者マスターの「自動引継ぎ対象」がONか確認してください。自動引継ぎは「今日を初めて開いたとき」だけ動きます。あとから引き継ぎたいときは「前日の申し送りをこの日に引き継ぐ」を押してください。

未来日を開いたら申し送りは作られる？

作られません。過去日・未来日は開いて見るだけでは何も作成・変更されません。先の日付を続けて開いても、申し送りが連鎖して作られることはありません。その日へ引き継ぎたいときだけ「前日の申し送りをこの日に引き継ぐ」を押してください。

退居した人の履歴を見たい

「履歴検索」で名前や言葉を入力すれば、退居した入居者の過去の申し送り・出来事・予定もそのまま検索できます（結果に「退居」と表示されます）。入居者マスターで「退居した入居者も表示する」にチェックを入れ、その人の「履歴を見る」からも開けます。

入居者を間違えて退居にした

入居者マスターで「退居した入居者も表示する」にチェックを入れ、その人の「復帰」を押すと在籍へ戻ります。退居中もデータは何も失われていません。

入居者を完全に削除したい

通常は「退居」を使ってください（履歴が残ります）。どうしても消す場合は、入居者マスターの「データ管理 → 管理用操作」にある「この入居者を完全削除」を使います。二段階の確認があり、過去の申し送り・予定・履歴も消えて元に戻せません。実行前にバックアップ保存を行ってください。

1つの Unit の日次データだけ消したい

入居者マスターの「データ管理 → この Unit の対象日データを全消去」を使います。表示中の Unit・対象日だけが消え、他の Unit は変更されません。全 Unit をまとめて消す操作は「管理用操作」の中にあります。

予定一覧を印刷したい

「予定一覧」タブの「予定一覧を印刷（A4 横・別紙）」を押します。印刷されるのは対象日1日分です。「全Unit」がONなら Unit 2〜5 をまとめて、OFF なら現在の Unit だけを印刷します。申し送り用紙とは別紙になります。

申し送り用紙に予定が出なくなった

仕様変更です。予定は「予定一覧」タブから別紙（A4横）として印刷します。申し送り用紙はその分、記録欄・申し送り欄を広く使えます。予定のデータは削除されていません。

保存できていない警告が出た

「⚠ 現在データをこのPCへ保存できていません」と出たときは、そのページを閉じると入力内容が失われる可能性があります。まず「いますぐバックアップ保存」でファイルへ保存し、プライベート（シークレット）モードで開いていないか、ブラウザの保存容量やサイト設定を確認してください。保存できる状態に戻ると警告は自動的に消えます。

BSが表示されない

入居者マスターの記録項目設定で、該当するBSがONか、対象曜日が正しいか確認してください。

木曜朝BSが水曜夜勤に出ない

夜勤の「翌朝BS」がONで、測定する朝の曜日が木曜日に設定されているか確認してください。

入居者が印刷されない

入居者マスターまたは申し送り入力で「空床」になっていないか確認してください。

予定一覧に予定が出ない

申し送り欄に書くだけでは予定登録されません。入居者カードの「＋予定を追加」から登録してください。

過去予定が見えない

予定一覧の「過去の予定も表示する」をONにしてください。

過去の申し送りを探したい

「履歴検索」を使用し、名前や言葉、Unit、日付範囲、種別で絞り込んでください。

別PCへデータを移したい

現在PCでバックアップ保存 → ファイルを別PCへ移動 → 別PCでバックアップ復元、の順に行ってください。index.html だけをコピーしてもデータは移りません（データはHTMLの中ではなく、そのPCのブラウザ内に保存されています）。

バックアップ復元が不安

復元すると現在のデータは読み込んだ内容へ完全に置き換わり、元へ戻せない場合があります。復元の操作では「先に現在のデータをバックアップ保存するか」を確認しますので、迷ったときは保存してから進めてください。ファイル形式が違う場合は「読み込めませんでした（形式が違います）」と表示され、現在のデータは変更されません。

印刷が横にならない

ブラウザの印刷設定で用紙がA4、向きが「横」になっているか確認してください。

データが消えた

使用しているPC・ブラウザ・index.htmlの保存場所が以前と同じか確認してください。バックアップがあれば復元してください。

申し送りメーカーへようこそ

最初に次の4つだけ設定すれば、毎日の操作はかんたんです。

1入居者マスター「入居者を追加」から部屋番号・名前を登録
2記録項目日勤・夜勤で必要な欄を設定
3毎日の入力変更がある申し送りだけ確認・修正
4印刷印刷プレビューを確認してA4横で印刷
詳しい説明は画面上部の「？ 使い方」、困ったときは「？ ヘルプ」から、インターネットなしでいつでも確認できます。
データはこのPCの、いま使っているブラウザ内に保存されます。HTMLファイルの中には保存されません。定期的に「バックアップ保存」を行ってください。
