本日の申し送り

その日に伝えることを書きます。ここに書いた内容がそのまま用紙へ印刷されます。

文章を整える

空床と退居のちがい

空床はその部屋が空いている状態、退居はその方が施設を出られた状態です。どちらも人数と印刷から外れます。退居しても過去の記録は消えません。

静養室へ移すとき（一時的に移すだけです）

「入居者」タブの一覧にある「いる場所」から 静養室 を選ぶと、その方を静養室へ移せます。登録し直す必要はありません。

  • これまでの申し送り・記録・予定はそのまま残ります
  • 静養室に1人でも入ると、印刷が自動的に5枚構成へ変わります
  • 元のユニットへ戻すときも、同じ「いる場所」から選び直すだけです
  • 静養室が0人に戻れば、印刷は自動的に4枚構成へ戻ります

毎週くりかえす予定（定期予定）

BSやターゲスのように毎週決まった曜日に行うことを登録しておくと、その曜日が来るたびに自動で用紙へ出ます。毎週入力し直す必要はありません。

日勤の予定

実施するその日の用紙の「日勤」欄に出ます。
例）ターゲス・毎週月曜・日勤を3件登録 → 月曜の用紙の日勤欄に3件出ます。

夜勤の予定（前日の用紙に出ます）

夜勤者が前もって準備できるよう、実施日の前日の用紙の「夜勤」欄に出ます。

  • 毎週月曜の夜勤 → 日曜の用紙の夜勤欄
  • 毎週火曜の夜勤 → 月曜の用紙の夜勤欄
  • 毎週日曜の夜勤 → 土曜の用紙の夜勤欄

月末・年末年始をまたぐ場合も、曜日の文字ではなく日付の計算で正しく前日を求めます。

ふえたり重複したりしない仕組み

定期予定は「毎週◯曜日」というルールだけを保存し、表示するときに計算しています。画面を開き直しても予定が増えたり、二重に登録されたりしません。1回だけの予定とは内部でも区別しています。

1回だけの予定

受診・外出・外泊・面会・行事など、その日だけの予定です。「入力」タブの入居者カードの「＋予定を追加」から登録します。

  • 用紙の左側に「予定：」として、その日の分だけ印刷されます。
  • 詳しい一覧は「予定」タブの「この日の予定を印刷（別紙）」からA4横で印刷できます。
  • 過ぎた予定は自動では消えません。「過ぎた予定を整理する」から確認して削除できます。

印刷

1ユニット＝1枚です。ユニットの内容が次の用紙へ混ざることはありません。

  • 静養室が0人のとき：ユニット2・3・4・5 の4枚
  • 静養室に1人以上いるとき：静養室・ユニット2・3・4・5 の5枚（静養室が先頭）
  • 静養室が0人に戻れば、自動的に4枚へ戻ります。
  • 固定記入例は人数にも印刷にも含まれず、保存・検索もされません。

人数が多いユニットは文字が自動的に小さくなります。入りきらない人がいる場合は、印刷プレビューの下に「要確認」として名前が出ます。

用紙はA4・横、倍率は「100%（既定）」にしてください。両面印刷を使うかどうかは、ブラウザの印刷画面で選んでください。

保存・バックアップ・アプリの更新

データはどこにあるか
  • データはこのPCの、いま使っているブラウザの中に保存されます（インターネットへは送信されません）。
  • index.html というファイルの中には入りません。そのため、index.html だけを別のPCへコピーしてもデータは移りません。
  • 同じPCでも、別のブラウザ（Edge / Chrome など）で開くと別の保存場所になります。毎日同じブラウザ・同じ場所のファイルから開いてください。
ブラウザの「閲覧データの削除」「サイトデータの削除」を実行すると、保存データが消えることがあります。定期的なバックアップ保存を強くおすすめします。
バックアップの保存と復元
  • バックアップを保存：いまのデータをJSONファイルとしてこのPCへ保存します。
  • バックアップから戻す：保存したファイルからデータを戻します。実行前に、いまのデータを保存するか確認します。
  • ファイルが壊れている・形式が違う場合は復元を中止し、いまのデータはそのまま残します。
取扱注意：バックアップファイルには個人情報が含まれます。保存場所・持ち出し・廃棄は施設の規定に従ってください。
アプリを新しくするとき（重要）

新しい index.html へ差し替えても、これまでの入居者・申し送り・記録・予定・定期予定はそのまま残ります。保存場所（保存キー）はアプリを更新しても変えません。

  1. 念のため「バックアップを保存」を実行する
  2. いまの index.html を、新しい index.html で置きかえる（同じ場所・同じファイル名）
  3. いつもと同じブラウザで開く。データはそのまま表示されます

アプリを削除したり、ブラウザのデータを消したりする必要はありません。

このアプリでできないこと

このアプリは、申し送り・勤務記録を整理して印刷するための道具です。次のことは行いません。

  • 診断・医学的な判断
  • 投薬や投与量の判断、治療の提案
  • 緊急度の自動判定

「文章を整える」も、入力された事実を読みやすく並べ直すだけで、内容を勝手に足したり変えたりはしません。判断は必ず職員・医療者が行ってください。

通信について

このアプリは、外部サーバー・外部AI・解析サービスへの送信処理を一切実装していません。インターネットに接続していてもいなくても、同じように動きます。万一そうした処理が混ざっても止まるよう、ブラウザ側で通信を禁止する設定（Content-Security-Policy）もこのファイルに書いてあります。

ブラウザの設定もご確認ください

このアプリは、入力欄のスペルチェック・入力予測・オートコンプリート・翻訳を止めるよう指定していますが、ブラウザ側の設定が優先されることがあります。管理者の方は、職場PCで次をOFF（またはローカル処理）にしてください。

  • Edge：文章作成の支援（Microsoft Editor の「拡張」）、文法とスペルチェック、テキスト予測
  • Edge / Chrome：住所・パスワードなどの自動入力、ページの翻訳の提案、拡張スペルチェック
  • Windows：入力データの送信、IME のクラウド候補
  • ブラウザのプロファイル同期（サインインして同期する設定）

また、バックアップしたファイルは、クラウド同期フォルダ（OneDrive など）ではなく施設の規定に沿った場所へ保存してください。

困ったとき

入力した内容が消えた

いつもと同じPC・同じブラウザ・同じ場所のファイルを開いているか確認してください。違うファイルを開くと、別のデータに見えることがあります。バックアップがあれば「バックアップから戻す」で復旧できます。

「保存できていません」と赤い警告が出る

すぐに「バックアップを保存」でファイルへ保存してください。プライベート（シークレット）ウィンドウで開いていないか、保存容量が足りているかを確認してください。

静養室の用紙が印刷されない

静養室に登録されている人が0人だと印刷されません（仕様です）。1人以上登録すると自動的に5枚構成へ変わります。固定記入例は人数に入りません。

夜勤の定期予定が当日の用紙に出ない

夜勤の定期予定は前日の用紙に出る仕様です。月曜夜勤なら日曜の用紙を確認してください。

印刷が横向きにならない

ブラウザの印刷画面で、用紙を A4、向きを「横」にしてください。

見つかりませんでした。別の言葉でさがしてください。
