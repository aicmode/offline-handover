# 申し送りメーカー

医療・介護現場向けの「オフライン申し送り・勤務記録支援」Webアプリのプロトタイプです。アプリ本体・使い方・ヘルプは `index.html` だけで動作し、インターネット接続を必要としません。

## 主な機能

- Unit 2〜5管理
- 入居者マスター（入居中／空床／退居）
  - 退居にすると申し送り入力・実入居人数・印刷・自動引継ぎから外れ、過去の申し送り・予定・履歴は保持
  - 完全削除は「管理用操作」に隔離し、二段階確認
- 常設重要メモ
- 日付別申し送り
- 前日・過去日からのコピー
- 前日申し送りの自動引継ぎ（今日を初めて開いたときのみ。過去日・未来日は閲覧しても生成しない）
- 予定管理
- 予定一覧のA4横・別紙印刷（申し送り用紙とは分離）
- 入居者ごとの記録項目設定（日勤／夜勤を個別にON/OFF）
  - 標準項目：T / P / BP / SpO2 / 食事（朝・昼・夕）/ Hr（1回目・2回目）/ BS / BW / メモ
  - 項目ごとの曜日指定（毎日 または 月〜日の複数選択）
  - 施設独自のカスタム項目（項目名・勤務帯・曜日・単位・入力欄サイズ）
  - OFF の項目は用紙に出さず、残った項目が自動で詰まる
- A4横・Unit別表裏印刷
- 表15名 / 裏15名
- localStorageによるローカル保存（タブ切替・ページ離脱時に未保存分を即時保存／保存失敗時は警告表示）
- JSONバックアップ保存・復元（復元前バックアップの導線と形式検証つき）
- 外部API・クラウド通信なし
- 初回起動ガイド・検索できる使い方・困りごと別ヘルプを単一HTML内に収録

## 注意

このリポジトリは学習・デモ・ポートフォリオ目的のプロトタイプです。
実際の患者・入居者の個人情報は保存・公開しないでください。
